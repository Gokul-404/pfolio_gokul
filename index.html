    CNN-Transformer Neural Video Compression Engine

    A CNN and a Transformer shrink the video and a decoder rebuilds the frames. A learned model predicts probabilities for entropy coding, so the video is saved in my own compressed format. A FastAPI service with Docker and Pytest tests wraps it.

    AI Drift & Threat Detection for Cloud Environments

    Combines data drift detection with Isolation Forest anomaly detection, trained on NSL-KDD. It flags misconfigurations and possible intrusions across IAM policies, storage buckets and cloud security settings, and retrains automatically when features drift significantly. A centralized dashboard shows model health and alerts.

    Publication: IJEDR
